# netflector package repository

pkg(8) repositories for [netflector](https://github.com/netflector/netflector),
served over GitHub Pages.

Trees live under `opnsense/${ABI}/latest` for FreeBSD:14 and FreeBSD:15 on amd64
and aarch64. Everything is generated and signed by the publish workflows in the
main repository; nothing here is edited by hand.

Install instructions live in the
[netflector README](https://github.com/netflector/netflector#readme).
